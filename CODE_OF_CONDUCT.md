Code of Conduct

Our Pledge

We are committed to creating a respectful, inclusive, and welcoming environment for everyone participating in this project.

Expected Behaviour

All contributors are expected to:

* Treat everyone with respect and courtesy.
* Use polite and professional language.
* Accept constructive feedback.
* Respect different opinions.
* Help maintain a positive learning environment.

Unacceptable Behaviour

The following behaviours are not acceptable:

* Harassment or discrimination.
* Insults, threats, or personal attacks.
* Sharing private information without permission.
* Deliberately disrupting project discussions.

Reporting Issues

If you experience or observe inappropriate behaviour related to this project, please contact the project maintainer.

Enforcement

The project maintainer will review reported concerns and take appropriate action to maintain a respectful environment.

Scope

This Code of Conduct applies to project discussions, Issues, Pull Requests, contributions, and other project-related activities.
